WHAT WE MAKE

Three pieces, one process.

An engine, an agent and a tuner, built together, measured together, and run on one card.

Inference engine

vivace

The engine. Open models on the GPU you have, serving many conversations at once from one card, with a finished conversation parked so the next turn starts where it left off. Open source under Apache 2.0 soon.

Measured results
Hardware
NVIDIA RTX 30, 40 and 50 series (CUDA). Apple M5 (Metal).
Models
GGUF. Llama 3, Qwen 2.5 and 3, Qwen 3.5 hybrid, Mistral. Q4_K_M and Q8_0.
Serves
/v1/chat/completions and /v1/messages on localhost. Works with Claude Code, Qwen Code and OpenCode.
Faults
A GPU fault exits with code 3; vivace supervise restarts it and chat --resume picks the transcript back up.
Correctness
Top-1 agreement with llama.cpp on the same file at or above 99 %, with a bounded KL, in four modes.
Personal agent

Iris

The agent. It lives on your machine and knows the difference between reading and spending: it quotes its sources by file and line, keeps its memory in plain text you can open, and asks before anything leaves the computer.

Tool-choice accuracy
Permissions
Four classes: Read, WriteLocal, WriteExternal, Spend. Spending always asks; after untrusted input, every write asks.
Citations
From your documents, file and line. From the web, only quotes the saved page still shows.
Memory
Plain text files you can open, edit and delete, every write logged with its reason.
MCP
Runs as a server for other tools, and never offers them spending or writes outside this computer.
Skills
ask_docs, web_answer, read_papers, research.
Diagnosis and tuning

strided and gait

The tuner. A diagnosis whose every rule carries a citation, and a trial loop that changes one thing at a time, writes its prediction down first, and keeps the change only when the measurement proves it.

Inside one process
Rules
Each carries a citation: Roofline, PagedAttention, Sarathi-Serve, DistServe, Little's law. A rule without one will not load.
Confidence
Every finding has a number. Ambiguous evidence gives no diagnosis at all.
Trial
INTAKE → PREFLIGHT → BASELINE → APPLY → VERIFY → REVIEW → PACKET, with the prediction written before the change.
Keep rule
Kept only if the objective improves with the 95 % interval clear of zero; otherwise reverted through its declared inverse.
Authority
Performance knobs may change on their own. Anything that could change an answer needs a human.
